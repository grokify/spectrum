## [v1.21.0] - 2026-08-23 ([`043bb5a`](https://github.com/grokify/spectrum/commit/043bb5a))

### Highlights

- New OpenAPI 3 spec diffing: compare two specs across endpoints, operation IDs, and schema names, with a matching `oas3diff` CLI. Endpoints are compared generically (path variables normalized) so operationId renames do not mask shared endpoints.

### Added

- `openapi3.SpecMetadataDiff` with `SpecsDiff`, `ReadSpecsDiff`, and `SpecMetadata.Diff`/`Difference` to report the endpoints, operation IDs, and schema names unique to each of two specs and those shared ([`ba7e914`](https://github.com/grokify/spectrum/commit/ba7e914))
- `cmd/oas3diff` CLI to diff two OpenAPI 3 specs (JSON or YAML), following the `cmd/oas2meta` convention ([`3bd1212`](https://github.com/grokify/spectrum/commit/3bd1212))

### Dependencies

- _1 dependency update_

### Tests

- Cover `SpecsDiff` across endpoints, operation IDs, and schema names, including that a renamed operationId on a shared endpoint is not reported as an endpoint difference ([`a11d134`](https://github.com/grokify/spectrum/commit/a11d134))
